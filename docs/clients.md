# Подключение клиентов (этап 5)

Делайте это **после** [установки и настройки панели](install.md): на этапе 3 у клиентов меняется ID подписки, и
ссылки, выданные раньше, перестанут работать.

## 1. Где взять ссылку подписки

Ссылки собирать не нужно: панель выдаёт готовые.

1. Панель → **Клиенты** → в строке нужного клиента нажмите кнопку **ⓘ** (информация о клиенте).
2. В окне «Информация о клиенте» найдите блок **«Информация о подписке»**. В нём две ссылки, у каждой есть кнопки
   «копировать», «скачать» и **QR-код** (QR удобно показать с экрана компьютера и отсканировать телефоном):
   - **SUB** — подписка для INCY (и Happ);
   - **CLASH** — подписка для Clash Verge Rev и других клиентов на mihomo.
3. Ниже, в блоке **«Копировать ссылку»**, лежат ссылки на отдельные входы клиента (одна ссылка — один вход, например
   VLESS + XHTTP + Reality). Они нужны для ручного добавления одного входа; для обычной работы берите SUB или CLASH.

Для **AmneziaWG** есть отдельная подписка (адрес `…/awg-xxxx/…` — на итоговом экране установщика): она для приложений
Amnezia, не для INCY и не для Clash.

> ℹ️ Ссылки подписки строятся по ID подписки клиента. Если ID подписки сменили (этап 3.2) — копируйте ссылку заново.

## 2. Какое приложение выбрать

| | **INCY** (рекомендуем основным) | **Clash Verge Rev** |
|---|---|---|
| Платформы | Android, iOS/iPadOS, Apple TV, Windows, macOS, Linux | Windows, macOS, Linux |
| Ядро | Xray | mihomo (Clash.Meta) |
| Входы схемы | все: VLESS+TLS, Reality, Hysteria2, XHTTP+Reality (проверено) | Reality и XHTTP+Reality на свежем Xray могут не подключаться — [см. xhttp.md](xhttp.md#если-клиент-не-подключается) |
| Правила маршрутизации | профиль [hydraponique](https://github.com/hydraponique/roscomvpn-routing): РФ напрямую, YouTube/Telegram/GitHub и остальное через VPN | наш [`clash-universal.yaml`](../clash-universal.yaml): российское напрямую, заблокированное и нужные сервисы (Telegram и др.) через VPN, остальное напрямую |
| Когда брать | телефон, планшет, ТВ и компьютер; если какой-то вход не подключается | компьютер, нужны правила «напрямую всё, кроме заблокированного» |

Если сомневаетесь — ставьте **INCY**: он работает на всех платформах и со всеми входами схемы. Другие приложения
(Happ и пр.) подписка тоже умеет отдавать, но их поведение проверяйте у себя.

## 3. INCY

**Где скачать** (проверяйте, что ссылка ведёт на официальный источник):

| Платформа | Где |
|---|---|
| Сайт разработчика | [incy.cc](https://incy.cc) |
| iPhone, iPad, Apple TV, Mac на Apple silicon | [App Store](https://apps.apple.com/app/incy/id6756943388) |
| Android | [Google Play](https://play.google.com/store/apps/details?id=llc.itdev.incy); APK для устройств без Google Play — на сайте |
| Windows, macOS (в т.ч. Intel), Linux | [релизы на GitHub](https://github.com/INCY-DEV/incy-platforms/releases) |

> ⚠️ В **российском App Store** INCY с конца октября 2026 [недоступен](https://www.anti-malware.ru/news/2026-10-27-111332/51862)
> (в других регионах он есть). Варианты: сменить регион аккаунта Apple (например, на Турцию или Казахстан) либо
> использовать клиент с сайта разработчика на других платформах. Ситуация меняется, следите за новостями разработчика.

**Как добавить подписку:** возьмите у клиента ссылку **SUB** (или отсканируйте её QR). В INCY нажмите «+» → добавить по URL (или из буфера обмена) → вставьте ссылку →
дождитесь списка серверов → выберите сервер → подключитесь и разрешите системе создать VPN-подключение. Либо
откройте на устройстве ссылку вида `incy://import/<ссылка подписки>`.

## 4. Clash Verge Rev

**Где скачать:** [релизы на GitHub](https://github.com/clash-verge-rev/clash-verge-rev/releases) (Windows x64/x86,
macOS 11+ на Intel и Apple silicon, Linux). Документация: [clash-verge-rev.github.io](https://clash-verge-rev.github.io/).
Нужно ядро mihomo версии **1.19 или новее** (в свежих сборках оно уже встроено).

**Как добавить подписку:** возьмите у клиента ссылку **CLASH**. В Clash Verge Rev откройте раздел «Профили» → вставьте ссылку в строку адреса → «Импорт» →
выберите импортированный профиль → включите системный прокси (или режим TUN). Клиент получит узлы из подписки и
наши правила маршрутизации.

## 5. Если не подключается

- Сначала проверьте, что ссылка скопирована **после** обновления ключей клиента (этап 3.2), целиком, и что для Clash Verge взята ссылка **CLASH**, а для INCY — **SUB**.
- Reality и XHTTP+Reality в mihomo-клиентах: [xhttp.md](xhttp.md#если-клиент-не-подключается).
- Остальное — [troubleshooting.md](troubleshooting.md) и `healthcheck` на сервере.

> ℹ️ Правила профиля hydraponique для INCY/Happ отправляют через VPN **весь остальной интернет** (всё, чего нет в
> списке «напрямую»). Это сделано намеренно, но может поднять пинг в играх. Если нужно «напрямую всё, кроме
> заблокированного», используйте Clash Verge Rev с нашим профилем.
