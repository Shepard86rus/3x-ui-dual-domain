# Хаб-бот: один Telegram-бот на весь флот

Для тех, у кого много серверов. Обычный бот из `install` управляет одной нодой; хаб-бот по SSH управляет всеми сразу (статус, healthcheck, рестарты, клиенты). Ставится вручную, в `install` не входит.

## Файлы

- `tgbot-hub.sh` — сам бот (запускается как сервис `tgbot` на «хаб-ноде»).
- `hub-clients.sh` — модуль управления клиентами (подключается автоматически, если лежит рядом).
- `patch-hub.py` — одноразовый патч для подключения модуля клиентов к старой версии `tgbot-hub.sh`.

Токен бота и ваш Telegram ID бот берёт из `/etc/tgbot/env`. Список нод — в `/etc/tgbot/nodes.conf` (строки `no1|Название|IP`).

## Важно знать

- **SSH-ключ хаба = root-доступ ко всем нодам.** Токен бота и ключ храните как пароль от всех серверов.
- Бот слушается только вашего личного Telegram ID (проверяется и чат, и автор команды). Вписывайте личный ID, не ID группы.
- **Не запускайте `add-bot` на хаб-ноде**: он перезапишет сервис `tgbot` и хаб перестанет работать.
- Кнопки хаба: статус, версии, диск, лог, healthcheck, бэкап БД, рестарт панели и xray, обновление скрипта, а также «Весь флот» и «Флот hc». Кнопки «обновить панель» нет специально: её обновляют вручную.
