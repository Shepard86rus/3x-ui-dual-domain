# Интерактивное меню скрипта (с v0.6.8)

Запуск без аргументов в терминале открывает меню: в нём все основные команды скрипта, у каждой есть краткое описание, а по `?номер` открывается подробная карточка: что делает, какие бывают варианты, подводные камни, как откатить.

```bash
sudo bash 3x-ui-dual-domain.sh
```

Меню можно открыть и явно: `sudo bash 3x-ui-dual-domain.sh menu`.

## Когда меню не открывается само

Если у запуска нет терминала (pipe, cron, бот) или скрипт запущен не из файла (`bash <(curl ...)`), запуск без аргументов по-прежнему ставит `install`, как в версиях до 0.6.8. Меню запускает каждую команду отдельным процессом скрипта, поэтому ему нужен файл: скачайте его командой из [docs/install.md](install.md) и запустите.

## Как пользоваться

| Ввод | Что происходит |
|---|---|
| номер (`3`) | выполнить пункт |
| `?номер` или `номер?` (`?4`) | показать карточку пункта, ничего не запуская |
| `0` | выход |

Пункты, которые меняют сервер, помечены ⚠. Перед запуском такого пункта меню показывает последствия и просит ввести `yes`; Enter или любой другой ответ отменяет запуск.

## Пункты

| № | Команда | Что делает |
|---|---|---|
| 1 ⚠ | `install` | установка с нуля на чистый сервер |
| 2 | `upgrade` | обновление самого скрипта (с проверкой sha256) |
| 3 | `healthcheck` | проверка сервера, ничего не меняет |
| 4 | `add-xhttp` | третий вход XHTTP+Reality на отдельном имени ([xhttp.md](xhttp.md)); меню спросит имя |
| 5 ⚠ | `remove-xhttp` | убрать XHTTP; спросит, удалять ли сертификат |
| 6 | `panel-tunnel` | печатает команду SSH-туннеля к панели, ничего не меняет |
| 7 ⚠ | `rebind-ip` | сменить IP в nginx после смены адреса у провайдера ([ip-change.md](ip-change.md)) |
| 8 | `add-swap` | swap-файл (512M, 1G или 2G) |
| 9 | `remove-swap` | убрать swap-файл, созданный `add-swap` |
| 10 | `backup` | зашифрованный архив сервера; спросит имя файла и нужны ли сертификаты |
| 11 ⚠ | `restore` | восстановить архив на сервер с выполненным `install` ([migration.md](migration.md)) |
| 12 | `add-bot` | поставить или обновить Telegram-бота ([telegram-bot.md](telegram-bot.md)) |
| 13 ⚠ | `remove-bot` | удалить бота |

## Чего в меню нет

`add-vls`, `add-reality`, `add-hy2`, `add-h2`, `add-reality-front` и `panel-path` в меню не вынесены: `install` ставит всё это сам. Команды остаются в скрипте и работают из командной строки, как раньше. Они нужны для серверов, поставленных старыми версиями: например, после `upgrade` на установке версии 0.6.0 и старше один раз запустите `sudo bash 3x-ui-dual-domain.sh panel-path` (подсказывает healthcheck).
